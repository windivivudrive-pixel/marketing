# CreatorFlow Remotion Starter

This project renders a data-driven vertical short. Edit only `src/data/profile.json`, `episode.json`, and `captions.json`, then place local media under `public/`.

```bash
npm ci
npm run validate
npm run lint
npm run dev
npm run render
```

Use a new versioned output name for every approved revision. The demo intentionally renders without paid media or audio. A final episode requires the exact voice file before caption and beat timing are locked.
